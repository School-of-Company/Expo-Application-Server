# Claude instructions

Read [AGENTS.md](AGENTS.md) first. It holds the shared test and report rules and points to `.claude/rules/*.md`, which hold this repository's architecture, contracts, preregistration, logging, database, and Git workflow rules.

For task-specific guidance, use the matching skill in `.claude/skills/`. Claude hooks and settings are in `.claude/hooks/` and `.claude/settings.json`. Treat skill examples as examples; check the current Kotlin source when an example differs from it.
